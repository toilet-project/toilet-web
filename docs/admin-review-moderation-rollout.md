# 작성 리뷰 운영 적용 · 2026-10-25

## 적용 범위

- 최신순 한 줄 목록과 10개씩 페이지 이동, 상세 평가·본문 표시
- 확인된 가이드 위반 5개 사유에 따른 관리자 삭제와 처리 이력
- 운영 가이드 공개와 기존 다국어 정책 정합성
- API 조회 인덱스 추가. 기존 리뷰·회원·보상·설정과 작성 제한은 유지

실제 사용자 리뷰를 삭제하는 방식으로 배포를 검증하지 않는다. 프리뷰용 읽기 전용 서버와 운영 API는 별개이며 운영에는 프리뷰 자격증명·차단 플래그를 포함하지 않는다.

## 배포와 되돌림

1. 검증된 PR을 병합하고 승인된 소스의 이미지만 빌드한다. 회원 기능을 일괄 중지하는 기본 API 배포는 사용하지 않는다.
2. 기존 유지보수 잠금, 최신 격리 복원 검증 기록, API·배치 이미지, 환경과 마운트의 일치 여부를 확인한다.
3. 공개 가이드 게시 후 기존 설정을 보존하는 API 이미지 교체를 실행한다. V45 조회 인덱스만 추가됐는지 확인한다.
4. API가 정상 동작한 뒤 관리자 화면을 배포한다. 기존 이미지·설정의 되돌림 기준을 배포 실행에 연결한다.
5. 실제 관리자 로그인으로 10개 페이지·상세·정책 사유 선택을 확인하되 최종 삭제를 실행하지 않는다. 배포 전후 리뷰·제출·성장·회원 자료의 비식별 집계와 서버 내 지문이 같고 건강 확인이 정상인지 검증한다.

이상이 있으면 먼저 관리자 화면을 이전 이미지로 되돌리고 API도 보존한 이미지로 교체한다. 조회용 인덱스를 삭제하거나 데이터베이스를 과거 백업으로 덮어쓰는 방식으로 되돌리지 않는다. 실제 관리자 삭제가 발생한 뒤의 이미지 되돌림은 삭제한 리뷰를 복구하지 않는다.

## 과거 백업 복원 시 필수 수동 문턱

기존 자동 검사는 회원 파기·작성자 연결 해제·성장 보상 재적용을 검증한다. 관리자 리뷰 삭제를 자동 재적용하거나 별도 영속 삭제 원장을 제공하지 않는다. 새 기능이 이 범위까지 해결했다고 표시하지 않는다. 현재 도구는 격리 복원 검사용이며 운영 DB를 자동 승격하지 않는다.

1. 운영 복원 전 쓰기를 중지하고 마지막 운영 시점까지의 `REVIEW_DELETED` 감사 이력을 확보한다. 필요한 필드는 리뷰 UUID, 사유, 가이드 버전, 처리 시각뿐이며 원문·작성자·연락처·위치를 복제하지 않는다. 보관은 기존 서버의 보호된 운영 경로에서 하며 사용자 PC나 공개 이슈에 기록하지 않는다.
2. 복구할 백업과 별도로 확보한 이후 삭제 이력의 완전성을 확인한다. 과거 DB 백업 속 감사 이력만으로 그 백업 이후의 삭제를 복원할 수는 없다. 이력이 유실되었거나 최신임을 증명할 수 없으면 복원본의 운영 승격을 보류한다.
3. 격리된 복원본에서 UUID가 정확히 일치하는 리뷰만 다시 제거한다. 숫자 ID만으로 삭제하지 않고, 이미 없는 UUID는 중복 삭제하지 않는다. 제출·보상 제외 연결과 24시간 작성 제한의 기존 처리 규칙을 유지한다.
4. 기존 성장 정산 규칙으로 영향받는 보상·경험치·배지·알림을 재검증하고 공개·내 리뷰·평균·휴지·대기·혼잡 집계에서 제외됐는지 확인한다. 회원 파기·작성자 연결 해제의 기존 재적용도 계속 필요하다.
5. 확인된 전체 삭제 UUID가 복원본에 남지 않고 두 번째 대조에서도 결과가 같으며 관련 데이터 정합성 검사까지 통과한 경우에만 별도 복원 승인을 받는다.

이 문서는 복원 시 판단과 대조 순서를 정한 운영 절차다. 실제 복원이나 실제 리뷰 삭제를 이번 배포에서 실행하지 않으며, 완전한 삭제 이력의 영속 보관·자동 재적용은 후속 개선으로 구분한다. 최근 24시간 이내의 기존 백업·격리 복원 검증 성공을 확인했다.
