# 영어 UI 1차 지원 계획

승인일: 2026-09-19 · 개발 5주차(9/14~9/20) 착수. 전체 완료일은 검증 범위를 확인한 뒤 정한다.

## 목표와 경계

자동번역 서비스 없이 영어 사용자가 화장실 탐색, 로그인, 리뷰·제보, 내 페이지와 알림을 이용하도록 한다. 한국어 기능과 주소는 유지한다. Google Cloud Translation 연결·비용 발생, 관리자 영어화, 운영 배포는 이번 착수 범위에서 제외한다. 공개 프리뷰 게시 전 동시 작업을 대조하고 운영 배포는 별도 승인받는다.

## 승인한 헤더

- 모바일 홈의 삼선 메뉴·로그인 버튼 자리를 현재 언어 국기 버튼으로 교체한다.
- 버튼 아래 드롭다운: 대한민국 국기 + KOR, 미국 국기 + EN. 선택 항목 체크, 바깥 클릭·Escape·재클릭으로 닫기.
- 닫혔을 때 국기만 표시하되 접근성 이름은 현재 언어와 언어 선택 동작을 설명한다. 국기는 플랫폼 이모지 대신 동일한 SVG 자산을 쓴다.
- 시각적 크기는 작게, 터치 영역과 키보드 포커스는 충분히 확보한다.
- 데스크톱 기존 메뉴는 유지하고 언어 선택을 추가한다.
- 기존 메뉴에만 있는 링크는 내 페이지 등 대체 접근 경로를 확인한 뒤 제거한다. 로그인과 로그아웃 기능은 유지한다.

## 원문 유지 정책

리뷰·제보 본문, 관리자 자유 답변, 자유 형식 운영시간·시설 설명은 원문을 유지한다. 공식 영문이 없는 시설명·주소는 한국어를 유지한다. API 열거형이나 명확한 정형 값만 영어 라벨로 표시하며 원본 DB를 번역문으로 덮어쓰지 않는다. 일일 작성 제한·수정 기간·거리 제한 등 업무 규칙과 한국 기준 시간은 변경하지 않는다.

## 동시 작업 안전

관리자 상세 작업은 별도 관리자/API 저장소에 있지만 사용자 웹 Worker의 /admin-toilets-preview/ 배포 경로를 공유한다. 별도 사용자 웹 작업도 진행 중이다. 구현은 독립 worktree에서 하고 다른 브랜치의 파일·DB·배포 설정은 수정하지 않는다. App·공통 스타일·Worker·분석 경로는 통합 충돌 후보이므로 게시 직전 다시 비교한다. 현재 확인만으로 이후 변경까지 무충돌이라고 단정하지 않는다.

## 구현 순서

1. 안전한 문구/경로 기반과 언어 선택 컴포넌트부터 단위 검증한다.
2. 공유 지도 레이아웃을 유지하면서 실제 영어 경로와 헤더를 연결한다. 미완성 영어 화면으로 사용자를 보내는 버튼은 운영 노출하지 않는다.
3. 기능별 문구를 변환하고 원문 유지 영역을 분리한다.
4. 캐시 무효화·SEO·로그인 복귀를 검증한 뒤 프리뷰에서 인수한다.

추적 근거는 관련 PR·테스트 링크로 간결하게 남기며 구현, 프리뷰, 운영 완료를 구분한다.

### 충돌 점검

- 관리자 [PR #107](https://github.com/toilet-project/toilet-admin-api/pull/107)은 관리자 정적 화면 파일을 수정한다. 현재 추가한 다국어 파일과 직접 겹치지 않는다.
- 별도 관리자 프리뷰는 사용자 웹의 Worker·프리뷰 도메인을 공유하므로 후속 배포 시 보존 확인이 필요하다.
- 사용자 웹 [PR #274](https://github.com/toilet-project/toilet-web/pull/274)는 App, 정책 화면, 리뷰, 이용분석을 수정한다. 현재 기반 파일과 직접 겹치지는 않지만 다음 화면 연결 단계에서 겹친다. 해당 작업을 덮어쓰지 않고 최신 변경을 반영한 뒤 문구만 분리한다. /en 상세 주소도 기존 분석의 정해진 페이지 분류로 처리하며 ID·검색어를 추가 수집하지 않는다.

### 문구 현황과 빠지는 접근 경로

초기 구문 분석에서 한국어 문자열 후보는 59개 파일, 1,110개다. 중복·정책 본문·시험 화면을 포함한 후보 수이며 번역해야 하는 고유 문구 수나 공수 확정치가 아니다. 우선순위는 App(149), 정책 본문(142, 별도 검수), 리뷰 시험 화면(134, 운영 범위와 구분), 제보 작성(53), 내 리뷰(41), 모바일 내비게이션/내 페이지(39) 순으로 분류한다.

모바일 삼선 메뉴의 이용약관·문의는 로그인 전 내 페이지 하단과 로그인 후 내 페이지 하단에도 접근 경로가 있다. 로그인은 내 페이지 및 기능별 로그인 안내에서, 로그아웃은 내 페이지에서 유지할 수 있다. 따라서 삼선 제거를 위해 새 관리자 메뉴를 만들거나 인증 기능을 변경할 필요는 없다.

## 화면·경로 연결 결과 · 2026-09-19

- 모바일 홈의 로그인·삼선 자리에 국기 버튼을 연결했다. 데스크톱은 기존 메뉴를 유지한다. 선택 메뉴의 화면 범위·Escape·포커스 이동을 시험했다.
- /en 및 /en/toilet/{id}는 한국어와 같은 지도 레이아웃을 사용한다. 언어 전환과 뒤로/앞으로 이동 시 지도 DOM, 확대 단계, 중심, 선택 시설이 유지되는 것을 확인했다.
- 첫 HTML부터 한국어/영어 lang이 올바르며 방문자 쿠키·헤더로 공개 캐시를 나누지 않는다. 기존 한국어 주소와 공유 시설 원본을 유지한다.
- 시설 변경 이벤트가 두 언어의 페이지를 모두 무효화한다. 영어 분석 주소에서도 시설 ID·쿼리를 제거하도록 기존 정규화에 최소 변경을 추가했다. 이용분석 PR 통합 때 이 변경을 대조해야 한다.
- 외부 로그인으로 이동하기 전에 로컬 영어 경로만 짧게 보관하고, 로그인 성공/실패 콜백 때 한 번 복원한다. 토큰·쿼리·좌표는 저장하지 않으며 허용 경로·만료·외부 주소 차단을 검사한다. 실제 소셜 계정 인수는 후속이다.
- 검색 입력·하단 내비게이션·상세 시설 항목·오류 일부를 영어 문구에 연결했다. 시설명·주소·자유문구는 원문을 유지한다.

### 검증과 배포 상태

단위·회귀 248개, 타입 검사, 린트, 최적화 빌드가 통과했다. 개발 모드와 최적화 빌드 각각 390px 모바일·1280px 데스크톱 브라우저에서 언어 전환·히스토리·합성 로그인 복귀를 확인했다. 지도 SDK·API·시설은 로컬 합성 데이터만 사용하고 외부 브라우저 통신은 차단했다. 실제 카카오 지도·iPhone·운영 소셜 로그인 시험을 대신하지 않는다. 시험 서버·브라우저는 종료했다.

영어 화면은 명시적으로 켠 프리뷰 빌드에서만 열리며 현재 noindex다. 운영 배포·공용 프리뷰 교체·main 병합은 수행하지 않았다. 동시 이용분석 배포 작업과 조율하여 게시를 보류하고 로컬 구현만 진행한다.
