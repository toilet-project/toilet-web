# 영어 UI 1차 지원 계획

승인일: 2026-09-19 · 개발 5주차(9/14~9/20) 착수. 전체 완료일은 검증 범위를 확인한 뒤 정한다.

## 목표와 경계

자동번역 서비스 없이 영어 사용자가 화장실 탐색, 로그인, 리뷰·제보, 내 페이지와 알림을 이용하도록 한다. 한국어 기능과 주소는 유지한다. Google Cloud Translation 연결·비용 발생, 관리자 영어화, 운영 배포는 이번 착수 범위에서 제외한다. 공개 프리뷰 게시 전 동시 작업을 대조하고 운영 배포는 별도 승인받는다.

## 승인한 헤더

- 모바일 홈의 삼선 메뉴·로그인 버튼 자리를 현재 언어 국기 버튼으로 교체한다.
- 버튼 아래 드롭다운: 대한민국 국기 + KOR, 미국 국기 + EN. 선택 항목 체크, 바깥 클릭·Escape·재클릭으로 닫기.
- 닫혔을 때 국기만 표시하되 접근성 이름은 현재 언어와 언어 선택 동작을 설명한다. 국기는 플랫폼 이모지 대신 동일한 SVG 자산을 쓴다.
- 시각적 크기는 작게, 터치 영역과 키보드 포커스는 충분히 확보한다.
- 데스크톱 기존 메뉴는 유지하고 언어 선택을 추가한다.
- 기존 메뉴에만 있는 링크는 내 페이지 등 대체 접근 경로를 확인한 뒤 제거한다. 로그인과 로그아웃 기능은 유지한다.

## 원문 유지 정책

리뷰·제보 본문, 관리자 자유 답변, 자유 형식 운영시간·시설 설명은 원문을 유지한다. 공식 영문이 없는 시설명·주소는 한국어를 유지한다. API 열거형이나 명확한 정형 값만 영어 라벨로 표시하며 원본 DB를 번역문으로 덮어쓰지 않는다. 일일 작성 제한·수정 기간·거리 제한 등 업무 규칙과 한국 기준 시간은 변경하지 않는다.

## 동시 작업 안전

관리자 상세 작업은 별도 관리자/API 저장소에 있지만 사용자 웹 Worker의 /admin-toilets-preview/ 배포 경로를 공유한다. 별도 사용자 웹 작업도 진행 중이다. 구현은 독립 worktree에서 하고 다른 브랜치의 파일·DB·배포 설정은 수정하지 않는다. App·공통 스타일·Worker·분석 경로는 통합 충돌 후보이므로 게시 직전 다시 비교한다. 현재 확인만으로 이후 변경까지 무충돌이라고 단정하지 않는다.

## 구현 순서

1. 안전한 문구/경로 기반과 언어 선택 컴포넌트부터 단위 검증한다.
2. 공유 지도 레이아웃을 유지하면서 실제 영어 경로와 헤더를 연결한다. 미완성 영어 화면으로 사용자를 보내는 버튼은 운영 노출하지 않는다.
3. 기능별 문구를 변환하고 원문 유지 영역을 분리한다.
4. 캐시 무효화·SEO·로그인 복귀를 검증한 뒤 프리뷰에서 인수한다.

추적 근거는 관련 PR·테스트 링크로 간결하게 남기며 구현, 프리뷰, 운영 완료를 구분한다.

### 지금 확인할 수 있는 내용

- 우측 국기 버튼으로 KOR/EN을 선택한다. 모바일 삼선·로그인 버튼은 언어 메뉴로 바꾸고, 로그인은 내 페이지와 리뷰·제보에서 접근한다.
- 지도·목록·상세, 로그인 안내, 리뷰·제보 입력, 내 리뷰·제보·알림과 날짜 필터를 영어로 이용한다.
- 언어 전환·앞뒤 이동 시 지도와 선택 시설을 유지한다. 마커 안내만 바꾸며 지도를 다시 만들지 않는다.
- 시설명·주소·자유 형식 운영시간·사용자 본문은 원문이다. 실제 작성자 이름은 유지하고 연결이 제거된 작성자만 Anonymous로 표시한다.
- 계정·가입 동의·탈퇴/복구의 안내를 영어로 볼 수 있다. 현재 약관은 원문과 대조한 영문 읽기 번역을 제공하고, 이전 버전은 정확한 한국어 원문을 표시한다.
- 시설은 Restroom으로 표시하고 검색/공유 설명에는 한국 여행객을 위한 지도라는 점을 안내한다. 변기 수와 화장지 표현은 별도로 유지한다.

### 검증 결과

- 기능 단위·회귀 268개 통과. 관리자 보존 검사를 포함한 통합 빌드 270개, 타입 검사·린트·CI 통과.
- 합성 환경의 320·390·1280px에서 언어 전환, 지도 유지, 로그인 안내, 공개 리뷰, 내 리뷰·제보·알림, 달력, 리뷰 작성·수정·연결 제거를 검사했다.
- 게시 후 실제 카카오 지도와 공개 시설을 사용해 320·390·1280px에서 한국어↔영어 전환, 원문 시설명 보존, 로그인 안내와 가로 넘침 없음을 확인했다.
- 공개 경로 정상 응답, 잘못된 시설 주소 404, 영어 HTML 언어·canonical·구조화 데이터, noindex와 HTML/RSC 외부 캐시 보호를 확인했다.
- 기존 관리자 프리뷰 파일 10개가 최신 관리자 소스와 동일하다. 운영 웹 버전은 배포 전후 같다.

실제 브라우저 검사는 새 비로그인 세션에서 수행했고 모든 쓰기 요청을 차단했다. 로그인·GPS 권한 승인·실제 리뷰/제보 작성은 하지 않았다. iPhone과 실제 소셜 로그인 인수를 대신하지 않는다.

### iPhone 국기 선택 오류 보완

- Safari 계열에서 언어 항목을 터치하면 선택 처리보다 먼저 메뉴가 닫히는 오류를 재현했다. 터치 선택이 끝날 때까지 메뉴를 유지하도록 수정해 프리뷰에 반영했다.
- 수정 전 공개 프리뷰에서 실패하던 터치 전환이 수정 후 WebKit·Chrome 검사에서 통과했다. 실제 카카오 지도와 선택 시설을 유지한 한국어↔영어 전환을 확인했다.
- 반복 터치·버튼 재선택·바깥 누르기·취소된 터치·키보드 이동 및 닫기를 회귀 검사에 추가했다. 사용자 iPhone에서의 최종 재확인은 남아 있다.
- 최신 관리자 좌표 핀 변경을 포함한 관리자 프리뷰를 유지했고, 운영 서비스는 변경하지 않았다.

### 프리뷰 이용 시 구분

지도와 공개 시설·공개 리뷰는 실제 조회다. 리뷰 입력은 기존 **메모리 체험** 방식이므로 새로고침하면 초기화되며 운영 DB에 저장하지 않는다. 로그인·제보·계정 기능은 기존 API와 연결되어 있으므로 실계정 변경을 단순 시험으로 진행하지 않는다. 자동번역 서비스·운영 DB 변경·main 병합·운영 배포는 없다.

### 남은 작업

1. 새 계정·동의·약관 영문 프리뷰 인수, 자체 통계 문구 수정안 게시·운영 전 검토 및 영어 검색 보완 범위 확정.
2. iPhone 화면 인수와 실제 소셜 로그인 후 영어 화면 복귀 확인.
3. 운영 전 색인 범위·hreflang·사이트맵·prewarm/정리·캐시 격리 종합 점검.

사용자 기능 PR에는 관리자 시험 자산을 넣지 않았다. 기존 관리자 프리뷰는 별도 배포 통합 브랜치에서 보존한다. 이 WBS를 전체 완료로 처리하지 않는다.

- 한국어 원문·약관 버전·시행일·동의 항목·보관 기간은 변경하지 않는다. 확인한 현재 버전만 영문으로 연결하며 과거 동의 문서는 해당 한국어 원문을 그대로 연다. 조항을 찾지 못하면 오류를 표시하고 다른 문서로 대체하지 않는다.
- 시설 표현은 **Restroom**, 변기 수는 **Toilets**, 화장지는 **Toilet paper**로 구분한다. 개방화장실의 `Public-access restroom`은 현재 영업 중이라는 뜻이 아니라 공개 이용 대상 시설 분류다.
- 검색/공유 제목은 **Geupddong | Find public restrooms in Korea**. 설명과 홈 소개에 **한국을 여행하는 사람을 위한 공중화장실 지도**라는 맥락을 담았다. SEO·공유 설명·구조화 데이터도 같은 기준이다.
- 기존 `/toilet/{id}`, `/en/toilet/{id}`, 시설 식별자·API·DB 이름·실제 시설명은 유지한다. 영어 프리뷰는 계속 noindex이며 사이트맵에 공개 색인용으로 추가하지 않는다.

### 확인한 내용

- 단위/회귀 268건, 타입 검사·린트·최적화 빌드 통과.
- 합성 데이터의 320·390·1280px에서 기존 지도·언어 전환 흐름과 영문 동의·정확한 과거 원문·실패 후 재시도·탈퇴 처리 대기·선택 보관·복구·프로필 수정/사진을 확인했다.
- 동의 내용을 펼쳐도 자동 체크되지 않고, 선택 보관은 기본 미선택이다. 기존 API 요청과 처리 대기/완료 구분은 유지한다.
- 실제 HTML의 제목, 설명, Open Graph, Twitter, 언어 표시와 noindex를 검사했다. 원문 변경 시 영문을 다시 대조하도록 회귀 검사를 추가했다.
- 모든 계정 변경 시험은 로컬 가상 계정·가상 응답이다. 운영 회원 탈퇴·동의·사진 변경을 실행하지 않았다.
- 게시 후 실제 카카오 지도·공개 시설을 사용해 320·390·1280px 화면과 언어 전환을 확인했다. 영문 정책 4개 주소, 검색/공유 메타데이터, 잘못된 주소의 404, noindex·캐시 보호도 확인했다.
- 관리자 프리뷰 10개 파일과 운영 웹 버전은 게시 전후 동일하다. 표시 언어를 바꿔도 시설 원문과 지도는 유지한다.

### 운영 전 남긴 검토

최초 영문 프리뷰에서는 한국어 원문에 남은 ‘선택 분석·분석 허용 시’를 그대로 번역했다. 아래 후속 작업에서 실제 수집 코드와 대조한 수정안을 마련했다. 기존 프리뷰와 운영에는 아직 이 수정안이 반영되지 않았다. 코드·문구 대조는 법률 적합성 인증이 아니다.

사진 기능 활성화 여부 등 기존 프리뷰 설정도 유지한다. 프리뷰의 실제 계정 화면을 확인할 때 탈퇴·동의 변경을 시험 목적으로 실행하지 않는다.
