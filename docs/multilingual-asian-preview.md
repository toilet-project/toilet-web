# 일본어·중국어 지역별 UI 준비

현재 한국어(`/`)와 영어(`/en`)에 더해 일본어(`/ja`), 중국어 간체(`/zh-cn`), 대만 번체(`/zh-tw`), 홍콩 번체(`/zh-hk`)를 구별한다. 중국어 세 화면은 같은 언어의 단순 별칭이 아니라 서로 다른 UI·URL·번역 조회 코드다. 새 경로는 프리뷰 빌드에서만 열리고 검색엔진 색인을 허용하지 않는다.

시설 API의 `translations` 객체에는 `ja`, `zh-CN`, `zh-TW`, `zh-HK` 키를 각각 넣는다. 대소문자와 `_`/`-` 표기는 조회 시 정규화한다. 예를 들어 대만 번역이 들어오면 대만 화면에서 시설명과 번역된 주소를 보여준다. 이름이 비어 있거나 해당 지역의 레코드가 없으면 시설명·주소별로 기존 한국어 원문을 유지한다. 중국어에서 공통 `zh`나 다른 지역 레코드로 넘어가지 않는다. 서버의 공용 시설 캐시는 언어별 별도 데이터 복제 없이 번역 맵을 함께 보존하며, 기존 무효화 경로는 모든 언어의 상세 페이지를 포함한다. 단, **DB 적재만으로 이미 캐시된 화면이 즉시 바뀌지는 않는다.** 번역 적재 작업에서 시설 갱신 이벤트를 발행하거나 승인된 캐시 새로고침을 연결해야 한다.

지도·검색 제공처는 아직 그대로다. 영어는 기존 네이버 지도·영어 검색을 쓰고, 새 일본어·중국어 화면은 한국어 원문을 허용하는 기존 카카오 지도·키워드 검색을 쓴다. 네이버 지도 웹 SDK의 공식 언어 코드는 `ko`, `en`, `zh`, `ja`뿐이므로 중국어 세 지역의 지도 레이블을 각각 다르게 보여준다고 주장하지 않는다. 지역별 지도 SDK 전환과 현지어 검색 품질은 별도 검증 후 적용한다.

이번에는 진입·지도·시설 상세·리뷰 표시 등의 주요 고정 UI 문구를 우선 옮겼다. 계정·제보·리뷰 작성 흐름의 긴 안내와 법적 약관은 아직 번역 검수를 끝내지 않았으며 나머지 고정 문구는 한국어로 표시된다. 영어 약관만 번역되어 있으므로 새 언어의 약관 링크는 현재 한국어 원문으로 연결한다. 운영 활성화 전에는 이 문구들과 실제 모바일 화면, 로그인·제보·리뷰 흐름을 지역별로 검수해야 한다.
