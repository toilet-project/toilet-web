# 일본어·중국어 프리뷰 현황

2026-09-21 기준. [WBS #279](https://github.com/toilet-project/toilet-web/issues/279)의 검토용 구현이며 **운영 웹에는 아직 공개하지 않았다.** 프리뷰 경로는 `/ja`, `/zh-cn`, `/zh-tw`, `/zh-hk`다. 네 지역은 UI·URL·시설 번역 조회 코드를 따로 유지한다. 프리뷰에는 `noindex, nofollow`를 적용한다.

## 사용자가 보는 화면

- 로그인·가입·동의, 지도·상세, 내 페이지, 리뷰·제보, 알림·오류·날짜 필터 등 고정 UI 문구는 네 지역별로 준비했다. 현재 고정 문구 463개에서 한국어 대체값은 없다. 홍콩 번체는 대만 번체를 바탕으로 용어 차이를 덮어쓴다.
- 현행 약관은 각 언어의 참고 번역을 보여주고 한국어 원문을 펼쳐 볼 수 있다. 동의 조건과 정책 버전은 한국어 원문을 기준으로 유지한다. 번역되지 않은 과거 약관은 한국어 원문으로 표시한다. 법적 문구의 별도 검수와 공개 범위 결정은 남아 있다.
- 시설명·주소는 API의 해당 지역 번역을 필드별로 사용한다. 지역 번역이 없거나 번역명이 비면 한국어 원문으로 돌아간다. 중국어에서 공통 `zh`나 다른 지역 번역으로 대신하지 않는다. 실제 공개 API의 시설 12710에는 일본어·중국 간체 번역만 있어 대만·홍콩 화면이 한국어 원문을 표시했다.
- 공개 지도 API의 관리자 지정 그룹 표본 12914는 영어·일본어·중국 간체 그룹명과 시설명을 제공하고, 대만·홍콩 번역은 제공하지 않는다. 번역이 없는 그룹명이나 그룹 내 시설명이 한국어로 남을 때에도 그룹 카드에 원문 안내를 표시한다. 시설 유형은 공중·개방·이동 등 확인된 구조화 값만 번역하고 알 수 없는 유형은 원문을 유지한다.
- 시설 상세에 한국어 원문이 보이면 짧은 원문 안내를 붙인다. 자유 형식 운영시간, 공개 리뷰 자유글, 내 제보 입력값과 관리자 답변은 임의로 번역하지 않으며 원문 표시를 한다.

## 지도와 검색

| 화면 언어 | 기본 지도 | 검색 후보 |
| --- | --- | --- |
| 한국어 | 카카오 | 기존 카카오 키워드 검색 |
| 영어 | 네이버 영문 지도 | Cloudflare 검색의 영어 후보 |
| 일본어 | 네이버 일본어 지도 | 현재는 영어 후보만 |
| 중국 간체·대만 번체·홍콩 번체 | 네이버 중국어 지도 | 현재는 영어 후보만 |

네이버 지도 SDK는 중국어 지역별 지도 레이블을 구별하지 않아 세 화면에서 지도 언어 `zh`를 공유한다. UI와 시설 번역은 각각 유지한다. 사용자가 직접 고른 지도 공급자는 언어를 바꿔도 우선하고, 지도 중심·선택 시설·상세 카드를 가능한 한 유지한다. 지도 공급자와 검색 공급자는 독립적이므로 한국어 화면에서 네이버 지도를 직접 선택해도 검색은 카카오 방식이다. 일본어·중국어 검색어 또는 후보 번역을 지원한다고 안내하지 않는다. 검색 데이터·지도 공급자의 세부 조건은 [지도·검색 WBS #277](https://github.com/toilet-project/toilet-web/issues/277)과 [영어 검색 구성](cloudflare-english-place-search.md)을 함께 본다.

## 데이터와 캐시

API `translations`의 `ja`, `zh-CN`, `zh-TW`, `zh-HK`를 각각 조회한다. 키의 대소문자와 `_`/`-` 차이는 정규화하되 다른 중국어 지역으로 교차 대체하지 않는다. 지도·상세는 같은 시설 원본에 번역 맵을 실어 보내고 표시할 때 언어를 고른다. 상세 URL별 렌더링 캐시는 별도로 무효화해야 한다. **번역 DB 적재만으로 기존 R2/ISR 캐시가 즉시 갱신된다고 보장하지 않는다.** 번역 데이터 추가 작업에서 시설별 갱신 연결과 검증을 진행하며, 이번 UI 작업에서는 캐시 새로고침을 하지 않았다.

## 운영 전 남은 확인

- 실제 iPhone에서 네 언어의 전환→지도·목록→상세→로그인 안내·리뷰·제보·내역을 확인한다. 데스크톱 모바일 크기 점검은 실기기 검증을 대신하지 않는다.
- 빈 번역명·일부 주소 누락·지역 번역 부재의 더 넓은 실제 시설 표본을 확인한다. 관리자 지정 그룹은 표본 12914로 지역별 제공·누락과 원문 안내를 확인했으나 전국 표본 검토는 남아 있다. 현행 약관 참고 번역의 별도 검수도 남아 있다.
- 영어 검색 후보의 일본어·중국어 번역과 순위·좌표 품질은 후속 검색 데이터 작업이다. 네이버 지도 이용 조건·비용과 연결 WBS를 대조한다.
- 운영 공개·색인/SEO·캐시 정책은 별도 승인 후 진행한다. 프리뷰 검증이 운영 배포를 뜻하지 않는다.

자동 검사 304건, 타입·린트, 프리뷰/운영후보 빌드와 보안 검사를 통과했다. 프리뷰의 일본어·홍콩 번체 모바일 크기 상세 카드와 색인 금지 상태를 확인했다. 실제 iPhone 인수는 진행 중이다.
