# PC 헤더·상세 카드 UX — WBS #191

## 구현
- 헤더 내용은 최대 1,200px 중앙 폭에 배치한다. 좌측 급똥/검색, 우측 로그인·회원가입 또는 계정/알림 및 삼선 메뉴를 제공한다.
- 메뉴에는 기존 내 제보·계정·로그아웃·정책·문의 접근을 보존한다. Escape, 바깥 클릭, Tab 이동으로 닫히며 키보드로 열면 첫 항목에 포커스를 준다.
- 지도 카드 위치 계산을 다음 animation frame이 아닌 `useLayoutEffect`에서 실행한다. 즉, 화면에 표시하기 전에 실제 카드 크기로 위치를 확정한다.
- 기존 PC 최대 높이 460px을 로딩 단계부터 확보한다. 실제 지도 높이가 작으면 지도 여백을 제외한 크기로 줄이고 내용만 내부 스크롤한다. 따라서 API 응답 대기 없이 제목부터 표시하면서 로딩 후 위치가 튀는 것을 방지한다.
- 지도/카드 크기 변경 시 ResizeObserver로 경계를 다시 계산한다. 공간이 충분하면 마커를 피하고, 공간이 부족하면 지도 내부 배치를 우선한다. 아주 좁은 지도에서 마커와 카드가 절대 겹치지 않는 것은 보장하지 않는다.
- PC 배치 계산은 모바일에서 실행하지 않는다. 모바일 내비게이션·정책 페이지 통합·프로필 수정은 WBS #192에만 계획 등록했다.

## 검증
- lint, typecheck, 단위 검사 59건.
- 실제 공개 지도/목록을 사용하는 로컬 Chromium에서 1920×1080, 1440×900, 1024×600, 700×500 및 각 창 축소 상태 검사.
- 카드가 그려지는 매 프레임 경계, 첫 위치/상세 로딩/캐시 재선택 중 위치 변화, 지도 DOM 유지, 메뉴 키보드/Escape/바깥 클릭 확인.
- 로그인 메뉴는 격리된 사용자 응답 fixture로 검증하며 실제 계정 변경은 하지 않는다.
- 기존 375/390/430px 모바일 및 PC의 카드·제보 로그인 안내·뒤로/앞으로 회귀 확인.
- 개발 접속만을 위해 127.0.0.1, 192.168.0.4 두 고정 출처를 allowedDevOrigins에 등록했다. 운영 CORS 정책이나 API는 변경하지 않았다.

사용자 시안 확인과 메인/운영 배포는 별도 완료 조건이다.
