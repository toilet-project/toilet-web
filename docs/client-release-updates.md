# 클라이언트 배포 버전 갱신 및 모바일 카드 안정화

2026-09-06 · WBS #192 · 로컬 구현/검증 완료, 이번 변경의 preview/운영 배포는 미실행

## 디자인

- 단일/동일 위치 상세 카드의 공통 정보 행을 44px로 유지한다.
- 배경 없는 C안 아이콘 배치 + A안 1px 구분선. 별은 골드, 휴지는 초록 선형 아이콘.
- 제보는 기존 16px 말풍선/연필 SVG + 하단 `제보`, 44×44px 터치 영역을 유지한다.
- 평점·혼잡도·휴지 비율은 미구현 placeholder이며 실제 데이터처럼 임의 수치를 표시하지 않는다.

## 문제 범위와 근거

- 사용자 iPhone Chrome 영상: 카드 높이 변화 및 선택 위치에 기준점/0m 표시. 캐시 삭제로 일시 해소되었다는 제보만으로 CSS 캐시를 근본 원인으로 확정하지 않는다.
- 기존 CSS/JS는 해시 파일명과 `immutable` 장기 캐시를 사용한다. 이를 무조건 no-store로 바꾸지 않는다.
- 상세 데이터 메모리 캐시 TTL은 30초이며 로그인 쿠키/스토리지 전체 삭제는 하지 않는다.
- 전역 모바일 CSS를 지연 로딩 App에서 root layout으로 이동했다. `index.css → App.css → mobile-navigation.css → app-update.css` 순서를 한곳에서 고정한다. Next 문서의 전역 CSS 순서/라우트 간 잔류 경고를 고려한 보완이며 영상 원인 확정은 아니다.

## 새 버전 감지

- CI는 `NEXT_DEPLOYMENT_ID=commit-runId-runAttempt-target`을 빌드 시 주입한다. Next `deploymentId`와 `NEXT_PUBLIC_APP_VERSION`이 같은 값이다.
- `/version.json`은 동적 읽기 전용 응답이며 브라우저/공유 CDN 모두 `no-store`이다. 업무 DB/API 호출은 없다.
- 지도 최초 로드, 탭 복귀(focus/pageshow/visibilitychange), 보이는 탭의 5분 주기에 확인한다. 이벤트들이 겹쳐도 5분 내 1회, 동시 요청 1개, 10초 제한이다.
- 오프라인/비정상 응답/잘못된 버전은 조용히 무시한다. 실패나 버전 차이만으로 자동 새로고침하지 않는다.
- 새 버전이면 `업데이트` 안내. 제보/로그인/계정/동의/내 제보/알림, 모바일 다른 탭, 검색 입력, 그룹/지역 목록 열림 중에는 버튼을 비활성화한다. 입력 완료 후 사용자가 직접 누른다.
- Next의 자체 deploymentId 불일치 처리는 라우터가 수행하며 별도 안내 버튼과 다르다. Workers 전환 검증에서 이 경로도 확인해야 한다. 자체 라우터 전환까지 이 안내 버튼이 가로채는 것은 아니다.

## 상태 보호

- 사용자가 업데이트를 누른 순간에만 현 탭 `sessionStorage` 전용 키에 지도 중심/확대 수준/거리 기준 좌표·모드/현재 위치 표시/상세 펼침 상태/현재 화장실 경로를 저장한다.
- 서버 전송하지 않는다. 5분 유효·정확히 같은 경로만 복원하며 좌표/범위/형식을 검증하고 알려진 필드만 복사한다. 복원 성공 시 제거, 만료/잘못된 경로는 다음 읽기에서 제거한다.
- 주소록·로그인·토큰·제보 입력 내용은 저장하지 않는다. 저장소가 막혀 있거나 카드 URL 전환 중이면 새로고침하지 않는다.
- 복원 시 지도 중심과 거리 기준점을 별도로 적용한다. 선택 화장실/기본 시청/GPS로 중심을 다시 덮어쓰지 않는다. GPS 모드이면 위치 감시만 재개한다.
- 그룹/목록 상태는 직렬화하지 않고 닫은 뒤 갱신하게 한다. 일반 새로고침/뒤로가기의 모든 상태 보존을 구현한 것은 아니다.

## 실제 검증

- lint, TypeScript, Node 테스트 79개 통과.
- 격리 Node production smoke: 빌드 성공, deploymentId HTML/CSS URL 반영, version.json 값/no-store, 기존 SSR/메타데이터/사이트맵/서명 캐시 갱신/404 검사 통과.
- 개발 브라우저: 390×844 / 320×667, 정보 행·제보 44px, 가로/메트릭 넘침 없음, 제보 로그인 유도 유지.
- 30초 내 GS21세기주유소 → 한밭대로주유소 → GS21세기주유소: 거리 550m → 940m → 550m, 카드 높이 약 249.43px 유지.
- 격리 UI harness에서 실제 AppUpdateNotice 컴포넌트 사용: 새 버전 안내, 작업 중 버튼 비활성화/입력 유지, 명시 클릭 후 reload/지도 중심 36.35·기준 36.4·레벨 4 복원 확인. 실제 계정/제보/DB 변경 없음.

## 배포 전/후 남은 확인

- CI Workers 빌드 및 원격 preview 배포, 구버전 탭을 유지한 실제 버전 전환 검사.
- 실제 iPhone Chrome: 재선택/뒤로가기/탭 복귀/키보드/제보 입력 중 업데이트 확인. 첨부 영상의 원인은 아직 확정하지 않았다.
- Workers에서 버전 응답·CDN bypass·Next deployment header를 확인한다. Cloudflare 전역 캐시 규칙이 no-store를 덮어쓰지 않아야 한다.
- 이 기능을 모르는 기존 탭은 첫 한 번 재접속/새로고침해야 새 감지 코드가 설치된다. 이미 실행 중인 구버전 JS를 서버에서 강제로 교체할 수 없다.
- 수동 빌드도 고유한 `NEXT_DEPLOYMENT_ID`를 지정해야 한다. 미설정 시 `development`로 감지가 비활성화된다. CI 산출물은 ID가 포함된 동일 파일을 그대로 배포한다.
- 보이는 지도 탭당 최대 시간당 12회 버전 요청이 추가된다. 현재 기능은 캐시 무료화/Workers 요금제 변경을 수행하지 않는다.

## 롤백

이전 Worker 산출물로 롤백 가능하며 DB migration은 없다. 감지 기능을 끄려면 다음 빌드에서 deployment ID/감지 코드를 조정한다. CSS 전체 캐시 삭제나 인증 저장소 초기화를 롤백 수단으로 쓰지 않는다.

근거: 설치된 Next 16.3.4의 CSS 및 deploymentId 문서와 [공식 deploymentId 안내](https://nextjs.org/docs/app/api-reference/config/next-config-js/deploymentId).
