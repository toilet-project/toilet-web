# 지도 패널 분리 검증

## 변경 범위

지도 SDK 생성·정리, 시설 선택·상세 캐시·라우팅은 기존 연결을 유지한다. 장소 검색의 상태·300ms 지연·요청 취소를 `usePlaceSearch`로 분리하고 검색창 닫기·장소 선택·새 검색어 입력 시 이전 응답을 즉시 무효화한다. 요청을 중단할 수 없는 SDK도 늦은 결과를 반영하지 않는다.

모바일 내비게이션은 계정 화면과 분리한다. 모바일 계정·알림 화면, 정보 제보, 빠른 제보, 데스크톱 내 제보·계정 패널은 열 때 불러온다. 필수 약관 동의·계정 복구 화면의 기존 진입 조건은 유지한다.

각 패널은 로딩·실패 안내와 재시도를 제공한다. 재시도는 실패를 기억하는 React.lazy 인스턴스를 새로 만든다. 로딩 중 모달 닫기·Escape·키보드 포커스를 지원하고, 회원별 기존 키와 최신 전달값으로 이전 회원의 지연 화면을 표시하지 않는다.

## 로컬 검증

- 타입 검사·정적 검사·전체 자동 검사 통과. Windows 체크아웃의 생성 SVG 줄바꿈만 원래 LF로 정규화해 검사했으며 SVG와 생성 규칙은 변경하지 않았다.
- 별도 브라우저 검증 화면에서 최초 실패 후 재시도 성공, 로딩 중 Escape로 닫은 뒤 완료해도 재등장하지 않음, 로딩 중 A→B 회원 전환 후 B만 표시됨을 확인했다. 검증 화면은 제품 배포에 포함하지 않는다.
- 동일 Next.js 버전·운영 기능 설정으로 변경 전후 빌드를 비교했다. 지도 주청크는 127,624→101,009바이트, gzip은 37,136→30,711바이트였다. 이것은 주청크의 크기이며 전체 초기 JavaScript·전송량·지도 표시 시간의 감소율로 해석하지 않는다. 별도 공통 청크·SDK·네트워크·캐시는 각각 영향을 준다.

## 출시 확인

프리뷰·운영 후보 CI와 상세 캐시 교차 배포 검사를 통과한 산출물로 검증한다. 실제 지도·검색·시설 재선택·뒤로/앞으로·언어 전환, 모바일 패널·기존 회원의 계정 화면을 읽기만 수행한다. 제보·리뷰·좋아요·프로필 저장·탈퇴·알림 읽음 기록은 실행하지 않는다.

운영 반영 여부와 최종 결과는 [지도 최적화 WBS #359](https://github.com/toilet-project/toilet-web/issues/359)에 갱신한다. 실제 기기의 위치 권한·성능 백분위 측정과 지도 SDK 생명주기 전체 추출은 이번 변경의 완료 조건에 포함하지 않는다.
