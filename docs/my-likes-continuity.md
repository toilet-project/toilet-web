# 내 좋아요 정렬·목록 복귀 상태

2026-10-02 · 내 좋아요 후속 개선. 운영 배포는 별도 승인 단계.

- 처음은 최근 좋아요 순. 같은 브라우저 탭에서는 선택한 정렬을 유지한다.
- 상세를 열었다 돌아오면 거리 정렬 기준 좌표, 열었던 페이지 수, 스크롤 위치를 복원한다. 상세 위치나 새 GPS 응답 때문에 목록이 재정렬되지 않는다.
- 거리순을 명시적으로 새로 선택하면 새 GPS 좌표로 정렬한다. 실패하면 기존 정렬을 유지하고 재시도할 수 있다.
- 좋아요 **추가 성공** 때만 최근순·첫 페이지·맨 위로 초기화하고 새 위치를 확인한다. 취소는 선택한 정렬을 유지한다. 실패·상세 열람은 초기화 사유가 아니다.
- sessionStorage에는 회원 구분값과 정렬값만 보관한다. 좌표·페이지·스크롤은 현재 문서 메모리에만 두며 새로고침하면 위치를 다시 확인한다. 로그인·토큰·시설 목록 응답은 저장하지 않는다.
- 목록은 복귀 시에도 인증 API에서 다시 조회한다. 이미 열었던 페이지를 복구한 후 스크롤을 맞춘다. 사용자 화면에서 숨겨진 시설을 이전 응답으로 계속 표시하지 않는다.
- 로그아웃·인증 만료·탈퇴·다른 회원 전환 시 이전 상태를 버린다. 이전 화면의 늦은 응답은 새 정렬 또는 다른 회원 상태를 덮어쓸 수 없다.

## 검증

- 위치 무응답, 신선한 좌표 재조회, 저정밀 1회 재시도, 거절, 취소/늦은 콜백, 지도 복원 연결 회귀검사.
- 정렬·거리 기준·페이지·스크롤 보존, 새 좋아요와 취소 구분, 저장소 차단/오염, 회원 분리 회귀검사.
- 수정한 실제 컴포넌트를 로컬 격리 API(시험 65개)로 구동해 거리순 → 목록 중간 상세 → 시험 GPS 이동 → 복귀, 새 좋아요 추가 → 최근순/맨 위를 확인. 운영 데이터에는 쓰지 않는다. 이 화면은 사용자용 실 데이터 프리뷰가 아니다.
- 운영 R2/Redis 키·TTL·본문 템플릿·캐시 무효화·API/DB 변경 없음.
