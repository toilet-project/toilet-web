# 내 활동 필터 사용성 개선

작업일: 2026-09-12~13 · 개발 4주차 · [WBS #212](https://github.com/toilet-project/toilet-web/issues/212)

## 달라지는 화면

- 모바일 내 페이지·알림 및 그 안의 내 제보·내 리뷰 상세에서는 로고·메뉴가 있는 공통 헤더를 숨긴다. 제목·닫기·하단 내비게이션은 유지하고, 지도로 돌아가면 공통 헤더도 돌아온다.
- 내 페이지·내 제보·내 리뷰·계정 관리의 제목 위치를 맞췄다. 상세 화면의 제목과 닫기는 계속 화면 위에 남는다. 알림에서 제보로 이동할 때는 고정 제목 높이와 여백을 반영해 제보 윗부분이 가려지지 않게 한다.
- 모바일의 ‘계정 관리 · 동의 내역’은 팝업 대신 내 페이지 안에서 열린다. 약관은 작은 글씨로 펼쳐 읽고 다시 접는다. API가 연결한 원문·이전 정책 주소를 그대로 사용하며 문구나 동의 버전은 바꾸지 않는다.
- 가입 동의 화면도 각 약관을 펼쳐 읽는다. 펼치기와 체크박스는 별개여서, 읽기만 해서는 동의되지 않는다. 동의 저장·탈퇴 선택·처리 중 닫기 차단은 유지한다.
- 로그인 안내는 목적별 한 문장으로 줄였다. 리뷰는 ‘리뷰는 로그인 후 이용할 수 있어요.’만 안내하고, 모바일 알림·내 페이지의 비로그인 제목은 모두 ‘로그인 · 간편가입’으로 통일한다. 첫 가입 안내는 짧게 남기며 실제 로그인·동의·위치 확인 조건은 바꾸지 않는다.
- 로그인·간편가입 버튼은 알림·내 페이지와 리뷰·제보·일반 팝업 모두 Google → Kakao 순서로 맞춘다. 안내 문구도 구글·카카오 순서이며, 각 버튼의 인증 연결은 그대로 유지한다.
- 별도의 ‘필터’ 접기·펼치기 행을 없앴다. 기간·제보 상태 항목이 스크롤 영역 맨 위에 바로 보인다.
- **필터는 화면 상시 고정이 아니다.** 목록을 내리면 필터도 함께 올라가 사라진다. 기존 달력은 유지하며 과거 버전으로 되돌리지 않는다.
- 400px 이상 내리면 하단 내비게이션 위 오른쪽에 작은 화살표·TOP 버튼이 나타난다. 누르면 필터가 있는 맨 위로 이동한다. 선택 조건과 불러온 내역은 유지한다.
- 날짜창만 목록 위에 겹쳐 표시한다. 알림에도 같은 방식을 적용해 열고 닫아도 목록 위치나 스크롤 길이가 바뀌지 않는다. 날짜 버튼을 다시 누르거나 바깥 영역·Escape·목록 스크롤로 닫는다. 데스크톱 알림에서는 Escape 한 번으로 달력만 닫는다.
- 달력 안의 스크롤은 목록에 전달하지 않는다. 실제 조회 조건을 바꿀 때만 목록을 새로 조회하거나 필터링한다.
- 시작일·종료일·적용을 한 줄로 정리했다. 기기 기본 날짜창 대신 서비스 색상의 달력에서 기간을 선택한다.
- 내 제보·내 리뷰의 기간·닫기·관리 버튼 높이를 조금 줄였다. 날짜 행도 낮추고 ‘적용’ 폭을 넓혀, 양쪽 날짜와 간격이 균형을 이루도록 했다. 글자 크기와 달력의 날짜 선택 크기는 유지한다.
- 달력은 월 이동, 선택 기간 강조, 오늘 표시, 미래 날짜 제한을 지원한다. 잘못된 기간은 적용하지 않는다.
- 달력의 월 제목·요일·주간 행 여백을 줄여 높이를 낮췄다. 날짜 글자와 누름 영역은 유지하며, 짧은 화면에서는 달력 안만 스크롤해 하단 메뉴를 가리지 않는다.
- 브라우저 기본 회색 터치 강조를 없애고 짧은 눌림 반응을 사용한다. 키보드 사용자의 초점 테두리는 유지한다.
- 같은 위치 화장실 목록에서만 제보를 접기 옆에서 개방시간 옆으로 옮겼다. 테두리·배경 상자 없이 작은 빨간 사이렌(20px)만 보이며, 누르는 영역은 44px로 유지한다. 단일 카드도 사이렌·제보 글씨를 빨간색으로 바꾸고 상자를 없앴다. 데스크톱에서는 스크롤바 여백을 맞춰 제보와 리뷰의 오른쪽 기준선을 일치시킨다. 접수 절차는 바꾸지 않는다.
- 모바일 마커에서 시작하는 드래그도 지도에 전달한다. 기존의 터치 시작 차단을 제거하고 짧은 탭만 선택으로 처리한다. 8px 이상 이동·긴 누름·다중 터치·취소는 상세 선택으로 처리하지 않으며, 키보드 선택은 유지한다.

## 검증 범위

- 합성 계정·내역으로 좁은 모바일 화면의 고정 제목, 함께 스크롤되는 필터, TOP 표시 기준·위치·복귀를 확인한다. 달력 열기 전후의 목록 위치와 스크롤 길이를 비교한다.
- 최근 7일·30일·전체·직접 날짜, 더 불러오기, 빈 목록·오프라인·로그인 만료 흐름을 함께 점검한다.
- 달력의 날짜 계산, 방향키 이동, 키보드 초점, Escape 닫기·초점 복귀를 점검한다. TOP은 제목으로 초점을 돌려주며, 동작 줄이기 설정에서는 부드러운 이동을 생략한다.
- 공유 날짜 필터를 사용하는 알림에도 같은 달력을 적용한다. API·DB·실제 회원 내역은 변경하지 않는다.
- 알림 달력은 320px·390px·1280px에서 일반 높이와 480px의 짧은 화면, 5주·6주 달을 확인한다. 알림에서 목록 중간·끝 제보로 이동하는 위치와 지도 헤더 복귀도 확인한다.
- 계정·가입은 합성 계정으로 제목 정렬, 약관 불러오기 실패·재시도, 이전 원문, 펼치기/동의 분리, 탈퇴 확인 취소·처리 중 닫기 차단을 검증한다. 실제 회원 가입·탈퇴·동의 쓰기는 하지 않는다.
- 마커는 로컬에서 이벤트 전달과 탭·드래그 구분을 검사하고, 프리뷰에서 실제 Kakao 지도의 이동을 확인한다. [공식 이벤트 설명](https://apis.map.kakao.com/web/documentation/#event_preventMap)을 기준으로 드래그 시작을 차단하지 않도록 한다.

## 공개 상태

프리뷰 검토용 변경이다. 실제 iPhone의 터치 느낌은 사용자 확인을 남겨 두며, 운영 배포 완료로 표시하지 않는다.
