# 내 활동 필터 사용성 개선

작업일: 2026-09-12~13 · 개발 4주차 · [WBS #212](https://github.com/toilet-project/toilet-web/issues/212)

## 달라지는 화면

- 내 제보·내 리뷰 제목과 닫기는 계속 화면 위에 남는다.
- 설명 문구와 전체를 둘러싼 초록 박스를 없앴다. 제목 아래의 얇은 필터 바만 연한 초록색으로 강조한다.
- 기본은 접힌 상태이며 선택 기간이 보인다. 누르면 흰색 필터 내용이 약 0.22초 동안 아래로 펼쳐진다.
- 필터는 목록 위에 겹쳐 표시한다. 열기·닫기·달력 펼치기로 목록 위치나 스크롤 길이가 바뀌지 않는다.
- 필터 바를 다시 누르거나, 목록을 스크롤하거나, 바깥 영역을 누르면 닫힌다. 키보드 Escape도 지원한다.
- 필터 안에서 날짜를 스크롤하는 것은 목록에 전달하지 않는다. 실제 조회 조건을 바꿀 때만 목록을 새로 조회하거나 필터링한다.
- 시작일·종료일·적용을 한 줄로 정리했다. 기기 기본 날짜창 대신 서비스 색상의 달력에서 기간을 선택한다.
- 달력은 월 이동, 선택 기간 강조, 오늘 표시, 미래 날짜 제한을 지원한다. 잘못된 기간은 적용하지 않는다.
- 브라우저 기본 회색 터치 강조를 없애고 짧은 눌림 반응을 사용한다. 키보드 사용자의 초점 테두리는 유지한다.

## 검증 범위

- 합성 계정·내역으로 좁은 모바일 화면의 고정 헤더, 좌우 배경 가림, 필터 애니메이션과 재개방을 확인한다. 열기 전·도중·이후의 목록 위치와 스크롤 길이를 비교한다.
- 최근 7일·30일·전체·직접 날짜, 더 불러오기, 빈 목록·오프라인·로그인 만료 흐름을 함께 점검한다.
- 달력의 날짜 계산, 방향키 이동, 키보드 초점, Escape 닫기·초점 복귀를 점검한다. 동작 줄이기 설정에서는 펼침 애니메이션을 생략한다.
- 공유 날짜 필터를 사용하는 알림에도 같은 달력을 적용한다. API·DB·실제 회원 내역은 변경하지 않는다.

## 공개 상태

프리뷰 검토용 변경이다. 실제 iPhone의 터치 느낌은 사용자 확인을 남겨 두며, 운영 배포 완료로 표시하지 않는다.
