# 회원 탈퇴·복구 — 활성화 직전 인계

현재 상태: 정책은 미공개 초안, 회원 기능은 점검 상태다. 이 문서의 완료 표시는 코드/검토 준비만 뜻하며 운영 변경이나 법률 검토 완료를 뜻하지 않는다.

## 확정한 처리 경계

- 탈퇴 시 로그인 세션을 폐기하고 이용을 중지한다.
- 복구용 정보는 별도 선택 동의 시 달력상 3개월만 보관한다. 동의하지 않으면 복구를 허용하지 않고 회원정보 파기를 시도한다.
- 제보·감사·좌표 변경의 업무 이력 자체는 기간 만료로 삭제하지 않는다. 해당 회원 연결과 개인정보가 포함될 수 있는 내용만 파기 범위다.
- 현재 서버의 암호화 백업이나 DB 변경 로그가 존재한다는 이유만으로 탈퇴 접수 자체를 영구 대기시키지 않는다. 검증된 복원 방지 보호가 필요하며 관련 사본이 사라지기 전 보호 기록을 없애지 않는다.
- 보호 대장 종료는 회원 기능 활성화와 별도다. 자동 종료 쓰기는 계속 비활성으로 유지한다.

## 사본·보호 기록 종료 운영 절차

| 단계 | 책임/행동 | 완료 근거 |
| --- | --- | --- |
| 최초 파기 | API/배치가 해당 회원정보 파기 후 부재 증빙 확인 | DB 부재, 대장/독립 기준 일치 |
| 사본 점검 | 운영자가 정기 백업·점검 결과와 복원 이력을 확인 | 백업, binlog, Redis 디스크, 과거 볼륨, 복원 임시물, 외부 사본의 범위 목록 |
| 보류 | 자료 누락/기한 미충족/남은 사본이 있으면 보류 | 사유와 다음 점검에 필요한 증거 기록. 빈 폴더/설정값만으로 부재 판정 금지 |
| 종료 검토 | 최초 신뢰 가능한 DB 부재 확인 후 최소 32일 및 실제 사본 소멸 등 기존 도구 조건 충족 확인 | 현재 DB 부재·복원 부재·독립 기준·키 복구·최근 검토 증빙 |
| 개별 종료 | 정확한 회원 보호 기록의 정리 후보를 운영자가 승인한 뒤 실행 | 후보/대상 일치, 단계별 복구 저널, 갱신한 독립 기준, 비대상 불변 |
| 실패/재개 | 신규 작업으로 덮지 않고 원래 작업과 최신 증거 재대조 | 모호한 응답·외부 변경·만료는 중지 및 재검토 |

32일은 기존 도구의 안전 검토 시작 기준이지 법정 기간이나 자동 삭제일이 아니다. 과거 사본이 더 오래 남으면 사유를 검토하고 보관 필요성을 다시 평가한다. 필요성이 끝난 개인정보를 임의로 무기한 보관하는 근거로 쓰지 않는다. 회원별 최종 종료 작업은 별도 승인 범위이며 전체 운영 로그/제보 정리로 확대하지 않는다.

현재 실제 사본이 모두 소멸했다는 판정은 내리지 않았다. 과거 미사용 볼륨 정리와 현재 Redis 비영속 확인은 전체 사본 부재 증명과 다르다. 상세 경로·회원정보·비밀값은 공개하지 않고 비공개 운영 기록에만 둔다.

## 기존 정책과 변경 안내

- 기존 공개 정책의 Git 원본: toilet-web `7f11474e92a88a16d1f648833dabb48f5b239e24`.
- 원본 SHA-256: `6ad2db769590202deec4e4be2b69035a0ca4ad3ddec2e83afb469c3625604fbc`.
- 원문의 표기일은 2026년 9월 1일이다. 당시 본문을 렌더한 [이전 정책 보관본](../public/policy-history/2026-09-01.html)을 추가하고 정책 페이지에 링크했다. 보관본 추가를 새 정책 시행으로 계산하지 않는다.
- 변경 안내 위치: 개정 정책 상단 공지/시행 안내, 계정 탈퇴 확인 화면의 별도 선택 동의와 정책 링크. 공개 승인 시 실제 공지일과 시행일을 같은 버전으로 확정한다.
- 공지일을 소급 입력하거나 계속 로그인한 것을 선택 보관 동의로 간주하지 않는다.
