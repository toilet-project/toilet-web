# 회원 탈퇴·복구 정책 공개 검토

상태: 운영자가 공개 내용을 승인했고 후속 요청으로 시행을 2026-09-10 18:00 KST로 앞당겼다. 공지 배포는 같은 날 17:45 KST를 기준으로 준비하며, 그 시각에 배포하지 못하면 과거 시각으로 공개하지 않고 후보를 다시 발행한다. 실제 공개 결과는 별도 배포 기록으로 확인한다. 회원 기능 활성화는 승인 범위 밖이며, 이 문서는 법률 자문이 아니다.

## 공지·시행 운영안

1. 최종 본문과 사본·보호 대장 종료 근거를 검토하고 정확한 웹 커밋/정책 버전을 기록한다.
2. 기존 정책 원문과 시행 기간을 보존한 뒤 변경 내용, 공지일, 시행일, 문의처를 공개한다. 기존 이용자에게 알릴 위치를 확정한다. 과거 날짜를 임의 입력하지 않는다.
3. 선택 보관은 공지를 읽었다거나 계속 로그인했다는 이유로 동의한 것으로 보지 않는다. 실제 탈퇴 화면에서 별도로 받는다.
4. 시행 시각 이후에만 배치 → API 순으로 활성화한다. 공개일과 시행일의 간격은 기존 약관과 변경 영향에 맞춰 결정한다. 임의의 7일/30일을 보편적 법정 의무라고 단정하지 않는다.
5. 승인된 시행 시각과 공지 배포 기준 시각을 UTC 초 단위로 소스에 고정하고 한국시간으로 표시한다. 실제 배포 시작/완료/공개 확인 시각은 배포 기록에 별도로 남긴다. 예정 시각 전에 공개하지 않으며 지연 시 후보를 재발행한다.

## 기술적 공개 증거

`accountPolicyPublication.ts`의 버전·공지/시행 시각을 정책 페이지 article에 같은 값으로 표시한다. API/배치 수동 전환은 두 실제 운영 페이지에서 공개 상태와 승인 버전·날짜가 일치하는지 확인한다. 초안 안내가 남거나 시행 시각이 미래라면 거절한다.

이 검사는 공개 내용의 현재 일치 검사일 뿐 법적 승인, 공지 이력, 전체 이용자 열람의 증명이 아니다. 개인정보 처리방침 전체가 검토 완료됐다는 표시로 사용하지 않는다. 실제 날짜 설정과 본문의 검토 안내 제거는 별도 승인된 공개 릴리스에만 포함한다.

## 공식 근거 확인 범위

불필요해진 개인정보의 파기 원칙과 별도 보존 예외를 고려해야 한다. 복구용 정보를 선택 보관하는 처리와 개인정보를 제거한 업무 이력 보존을 구분한다. [개인정보 보호법 제21조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029335625)

동의 사항은 구분하여 알아보기 쉽게 안내해야 하며, 방침 공개만으로 선택 보관 동의를 대신하지 않는다. [개인정보 보호법 제22조·제30조](https://law.go.kr/lsInfoP.do?lsId=011357)

공식 조문 확인은 2026-09-10에 수행했다. 위 운영안은 현재 코드와 확인한 조문을 대조한 내부 판단안이며, 특정 보관 방식 전체의 적법성을 확정한 법률 의견이 아니다.

최종 처리 경계·사본 종료 운영 절차·이전 정책 출처·승인 대기 항목은 [활성화 직전 인계](account-release-final-handoff.md)에 정리했다. 보호 기록의 조건부 보관을 무기한 보관 승인으로 해석하지 않는다.
