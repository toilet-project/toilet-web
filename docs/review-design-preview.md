# 현장 리뷰 디자인 프리뷰

연결 WBS: [WEB #205](https://github.com/toilet-project/toilet-web/issues/205), [API #105](https://github.com/toilet-project/toilet-api/issues/105), [정책 후속 DOCS #96](https://github.com/toilet-project/docs/issues/96).

## 현재 범위

사용자 의도에 맞게 `https://preview.geupddong.com/`의 **기존 지도·실제 화장실 카드·내 페이지에 리뷰 UI를 연결**했다. 화장실 정보와 기존 계정 기능은 원래 기능을 사용하지만, 리뷰만 React 메모리에서 체험한다. 리뷰 저장 API는 아직 없으며 새로고침·계정 전환 시 초기화한다.

2026-09-11 피드백 후 **통합 프리뷰의 비로그인 체험 우회를 제거**했다. 화면에서 ACTIVE/필수 동의 완료가 확인된 계정은 **작성창을 먼저 열어 임시 입력**할 수 있고, 기존 서버 세션 조회와 기기 위치 확인을 병렬로 진행한다. 두 검사가 모두 성공하기 전에는 등록 버튼과 저장 핸들러를 차단한다. 비로그인 상태면 기존 로그인 안내만 연다.

새 리뷰는 화장실 150m 이내·정확도 50m 이하·최근 1분 측정값을 요구한다. 매번 GPS 새 측정을 강제하던 `maximumAge: 0`을 제거하고 브라우저가 보유한 최근 1분 위치를 허용한다. 최초 측정 시각을 검사하므로 캐시 사용이 유효기간을 늘리지 않으며, 캐시가 없으면 새로 측정한다. 저장 시에도 서버 세션과 위치를 병렬 재검사한다. 오류 후 '다시 확인'은 새 측정을 강제하여 부정확한 캐시를 반복하지 않는다. 처음 GPS를 잡는 시간·권한 허용 시간까지 즉시 완료된다고 보장하지 않는다.

지도 기준점/검색 주소는 사용하지 않는다. 앱은 사용자 좌표를 별도 보관하거나 서버에 전송하지 않으며, 계정 전환/취소/화면 종료 뒤 늦게 끝난 검사로 작성창·로그인창을 다시 열지 않는다. 확인 실패 시 창 안에 이유와 재시도를 표시하고 입력은 보존한다. 기존 리뷰 수정은 동일 로그인 계정과 최초 작성 7일 기한을 검사하며 재방문을 요구하지 않는다.

이 검사는 **프리뷰의 클라이언트 접근 제한**이며 서버 리뷰 API 검증이나 방문 증명이 아니다. 브라우저 위치 조작을 완전히 막을 수 없다. 실제 저장 API에서 거리·소유권·신선도 등을 별도 검증하기 전 운영 기능을 활성화하지 않는다.

통합 UI는 `SITE_INDEXABLE=false` 빌드에서만 활성화된다. 운영 빌드에는 새 진입 버튼이 없다. `/review-preview`는 오류/기한 시나리오를 위한 기존 격리 실험실로 유지하며 운영에서는 404다. 디자인 검토의 기본 진입점은 별도 실험실이 아니라 **기존 지도 홈**이다.

- 카드 이름 우측: 사이렌 제보 / 평가 행 우측: 기존 말풍선·펜 계열 리뷰.
- 필수: 만족도/청결도 별점 1~5, 화장지 유무. 대기시간 기본 0분, 200자 자유글은 선택.
- 혼잡도 원활/대기/혼잡 선택 UI와 입력 필드를 제거하고, 항상 보이는 대기시간 바 0~60분/10분 단위로 대체했다. 60분은 '1시간 이상'. 0분도 저장하며 수정 시 기존 시간 복원, 다시 0분 선택도 유지한다.
- 10분마다 눈금/숫자 직접 선택, 가운데 30분 정렬. 내 리뷰 전문은 대기시간을 표시한다. 카드의 기존 혼잡도 자리는 최신 수정된 체험 리뷰의 0분이면 원활/양수면 대기로만 표시한다. 혼잡 판정 임계값이나 정식 집계 규칙을 임의로 확정하지 않는다.
- 상세 카드와 작성창이 같은 별 SVG를 사용한다. 작성 별은 밝은 금색, 정수 `n / 5` 점수를 별 바로 옆 같은 높이에 배치한다. 상단 체험 배너는 없으며 44px 별·버튼과 16px 글 입력을 유지한다. 작성창 높이/위치는 고정하고 내부만 스크롤한다.
- 150m 거리 안내를 짧은 한 줄로 표시하고 '다시 확인'은 접근 가능한 이름이 있는 44px 새로고침 아이콘으로 대체했다. 재확인 중 재클릭/등록을 막고 초록 점을 천천히 점멸한다. 모션 감소 설정에서는 점멸 없이 확인 중 문구를 표시한다.
- 별/슬라이더/버튼의 기본 회색 터치 하이라이트와 별 축소 효과를 제거했다. 키보드의 `focus-visible` 표시와 선택 상태 색은 유지한다. 실제 iPhone에서 보인 깜빡임이 모두 사라졌는지는 실기기 인수로 별도 확인한다.
- 작성 → 내 리뷰 → 전문 → 수정 / 작성자 정보 지우기. 최초 작성부터 7일 제한.
- 작성자 정보 지우기 후 자유글·선택 값·평가 유지, 작성자 '탈퇴한 사용자', 내 목록에서 제외. 회원 탈퇴와 구분하고 복구 불가를 확인창에서 설명한다.
- 별도 `/review-preview` 실험실에만 가상 위치/로그인/7일 경과/저장 실패 설정을 둔다. 실제 지도 화면에는 모의 로그인이나 위치 우회 옵션이 없다.

## 검증

### 근거리 실기기 확인용 가상 화장실

프리뷰 홈의 `#review-test=<위도>,<경도>` 전용 링크를 열면 브라우저에만 테스트 마커 1개와 카드를 만든다. 좌표는 링크에서만 읽으며 사용자별 주소·좌표는 소스/공개 WBS에 기재하지 않는다. 서버 시설 레코드·검색 목록·집계·SEO 경로에는 추가하지 않고, 음수 예약 ID는 상세 API에 조회하지 않는다. 주변 지도/타일 조회는 기존 지도 기능을 그대로 사용한다.

카드와 마커는 가상 지점임을 표시하고 실제 제보를 차단한다. 로그인·기기 GPS·150m/50m/1분 검사와 리뷰 메모리 저장은 기존 통합 프리뷰와 동일하다. 이 링크는 위치나 인증을 증명/우회하지 않는다. 프래그먼트를 제거하면 마커가 사라지고 변경하면 메모리 리뷰까지 초기화한다. 운영 빌드에서는 유효한 링크라도 아무 시설을 생성하지 않는다.

`tests/review-test-toilet-browser.cjs`는 개인 주소가 아닌 공개 장소 좌표로 마커 1개, 닫기/재선택, 로그인·거리 제한, 링크 추가/제거, 업무 쓰기·가상 ID 요청 0건을 확인한다.

`pnpm lint`, `pnpm typecheck`, `pnpm test`에 더해 `tests/review-preview-browser.cjs`로 격리 프리뷰를, `tests/review-map-integration.cjs`로 기존 지도·단일/목록 카드·내 페이지 통합을 검사한다. 브라우저 실행 시 `PLAYWRIGHT_PACKAGE`는 설치된 Playwright 패키지를 가리키며, `REVIEW_PREVIEW_ORIGIN`은 로컬 시험 주소 또는 `https://preview.geupddong.com`만 허용한다. 통합 시험의 계정은 브라우저 내 가상 데이터이고 업무 쓰기를 차단한다. 로컬 지도 SDK는 모형, 실제 프리뷰의 지도 SDK는 공개 카카오 지도다.

브라우저 검사: 생성/수정/작성자 연결 해제/본문 잔존/7일 경계/150m 실패/정확도 부족/오래된 측정/권한 거부/저장 직전 재검사와 입력 보존/세션 만료/비로그인 GPS 미호출/새로고침 초기화, 폭 320·390·1280의 가로 넘침, 첫 터치 가운데 30분 선택·모든 눈금·창 위치 유지. 추가로 별 SVG 일치·점수 수직 중앙 및 6~12px 간격, 회색 하이라이트 비활성, 기본 0분·30분 저장 후 0분 수정, 150m 안내 한 줄 전체 표시, 재확인 점멸·모션 감소를 검사한다. 리뷰/회원 쓰기 요청은 차단한다. 공개 프리뷰의 기존 Cloudflare `/cdn-cgi/rum` POST는 성능 측정으로 별도 집계한다. Chromium 모바일 에뮬레이션이며 실제 iPhone Safari/Chrome 인수와는 다르다.

대기 UX 회귀에서는 세션/GPS 응답을 모두 보류한 채 작성창이 먼저 보이는지, GPS만 완료되어도 등록은 막히는지, 두 검사 병렬 시작·새 측정 재시도·닫은 뒤 늦은 세션 만료 응답을 무시하는지를 확인한다. 측정한 창 표시 시간은 시험 환경의 결과이며 실제 GPS 소요시간 수치가 아니다.

## 다음 구현

서버 DB/API·소유권·위치 신선도 검증, 중복/도배 제한, 집계 유효시간, 실제 계정 탈퇴/최종 파기와의 연동은 아직 구현 완료가 아니다. 카드 숫자는 체험 리뷰만 집계하며 실제 서비스 통계가 아니다. 약관·위치 고지는 DOCS #96에서 후속 검토 후 공개한다. 프리뷰 배포는 운영 기능 활성화 승인이 아니다.
