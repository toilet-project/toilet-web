# 전체 페이지 SEO 점검 및 개선

2026-09-25 · 운영 기준 `299f2da` · 운영 공개 URL과 응답, 현재 라우트 및 스냅샷을 검사했다. 변경 후 응답 검증은 로컬 production 빌드 기준이다. 이 문서는 운영 배포나 검색 순위 개선을 주장하지 않는다.

## 조사 범위

- 운영 사이트맵 **37개 / 291,799개 URL 전체**: 중복, URL 형식, 언어별 경로, 현재 지역명과 행정구역 코드, 언어별 시설 ID 중복, 한국어 원본 대응을 검증했다. 모두 통과했다.
- 한국어 시설 51,911개, 영어 45,498개, 일본어 45,496개, 중국 간체 45,498개, 대만 번체 51,826개, 홍콩 번체 49,928개의 공개 시설 URL을 확인했다.
- 전국/시도/시군구 **273개 × 6언어 = 1,638개**의 제목과 설명을 생성하여 언어 내부 제목 중복 및 설명 누락을 검사했다.
- 릴리스의 지역 배정 시설 이름 스냅샷 **50,452개**에서 한국어 메타데이터 생성과 원본 불변성을 검증했다. 이 스냅샷은 현재 API 전체 상세 데이터와 동일한 모집단이 아니다.
- 메인, 전국/시도/시군구, 지역 시설 상세, ID 별칭 상세, 정책 4종, 계정, 404를 포함한 **70회 응답 / 67개 고유 경로**의 운영 HTML과 수정 빌드를 비교했다.
- 브라우저에서 메인 및 상세의 초기 HTML → 화면 로딩 후 H1 유지, 상세에 메인 H1이 중복되지 않는지 확인했다. 390×844에서 여섯 언어 메인의 가로 넘침도 없었다.
- 계정·검증/미리보기·오류·정책 이력·사이트 소유 확인 파일의 역할과 색인 제외를 소스에서 점검했다. 사적인 계정 페이지나 오류 페이지를 점수 목적으로 색인 허용하지 않았다.

291,799개 상세 HTML을 모두 요청한 검사는 아니다. 운영 원본 호출과 ISR/R2 캐시의 대량 생성을 피하기 위해 전체 URL/데이터 규칙 검증과 모든 공개 페이지 템플릿·언어의 응답 검증을 결합했다.

## 유지한 정책과 진단 해석

- 비교한 70개 응답의 **상태 코드, canonical, robots가 변경 전과 동일**하다. 외국어 메인/정책의 기존 noindex, 시설별 최신 번역 자격, 계정 및 미리보기의 검색 제외를 유지했다.
- 캐시 키, 수명, 무효화, R2 정리 작업은 수정하지 않았다. 향후 일반 웹 배포가 수행되면 기존 배포 정책은 그대로 적용된다.
- 점수 화면의 H1 -10, 메타데이터 -5, 이미지 -8, 링크 -1은 확장 도구 자체 규칙이다. Google의 순위 점수가 아니다. 해당 확장 도구로 수정 후 점수를 재측정하지 않았으므로 100점 등을 주장하지 않는다.
- **실제 DOM과 스크립트를 제외한 HTML에서 빈/`#`/`javascript:` 링크가 재현되지 않았다.** 홈으로 가는 `/` 링크는 정상 링크다. RSC 직렬화 문자열까지 정규식으로 읽으면 가짜 빈 링크가 잡혀 감사 스크립트에서 제외했다.
- 카카오 지도 타일과 접근 가능한 이름을 가진 마커 내부 아이콘은 콘텐츠 사진과 구분했다. 점수만을 위해 타일마다 반복 alt를 삽입하지 않았다. [W3C 장식 이미지 지침](https://www.w3.org/WAI/tutorials/images/decorative/)은 이러한 장식 이미지에 빈 alt 사용을 안내한다.
- 짧은 정책 제목이나 일본어·중국어 설명을 임의 문장으로 채우지 않았다. Google은 제목/설명에 해당 확장 도구의 고정 글자 수 범위를 요구하지 않는다. [제목 안내](https://developers.google.com/search/docs/appearance/title-link), [설명 안내](https://developers.google.com/search/docs/appearance/snippet).

## 검증과 재실행

- production 설정 Next.js 16.3.4 webpack 빌드 및 TypeScript 통과.
- 전체 테스트 **389개 통과**. 추가 SEO 검사에는 모든 지역 제목, 전체 이름 스냅샷, 언어별 Place의 실제 주소/동일 ID, 공유 이미지의 실제 크기가 포함된다.
- lint 오류 없음. 기존 React Fast Refresh 및 effect 상태 변경 경고 6건은 별개로 남아 있다.
- 브라우저에서 제목·링크·상세 전환을 확인했다. 로컬 호스트에서는 지도 SDK 로딩이 실패했으므로 실제 지도 타일/마커 렌더링 검증은 배포 환경에서 다시 해야 한다. 지도 서비스 설정은 바꾸지 않았다.
- 서버 HTML의 계정 초기 로딩에는 H1이 없고, 잘못된 언어 경로 404는 Next 오류 셸을 반환한다. 이들은 noindex 대상이며 이번 공개 페이지 SEO 개선의 통과 조건으로 삼지 않았다.
