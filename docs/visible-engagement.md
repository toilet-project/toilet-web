# 웹 체류시간 측정 보정

## 달라지는 점

화면이 보이고 브라우저의 포커스가 있는 시간만 합산합니다. 다른 탭·앱으로 이동하거나 페이지가 숨겨지면 멈추고, 돌아오면 다시 이어서 측정합니다. 화면을 켜 둔 채 읽는 시간도 포함하므로 **실제 주의 집중 시간을 증명하는 지표는 아닙니다.**

- 활성 상태에서 30초마다 새로 누적된 시간만 전송합니다.
- 비활성 전환·페이지 이동·종료 때 남은 시간을 전송합니다.
- 뒤로가기로 복원된 페이지는 재개하지만 이미 전송한 시간은 다시 보내지 않습니다.
- 1초 미만은 같은 페이지에서 이월하고, 페이지를 떠날 때 남은 1초 미만은 버립니다.
- 브라우저 강제 종료·네트워크 실패에서는 마지막 구간이 유실될 수 있습니다. 운영체제가 상태 변경을 통지하지 않은 절전 시간도 완전히 구분할 수는 없습니다.

## 기존 분석과의 관계

기존 `engagement` 이벤트와 초 단위 합계를 그대로 사용합니다. 방문·페이지뷰 이벤트를 추가하지 않고 개인 식별값·클릭 내용도 새로 수집하지 않습니다. 활성 탭의 정기 요청은 분당 2건이며 기존 API의 분당 120건 제한 안에 있습니다. 탭 전환 등에 따른 마지막 구간 요청은 별도입니다.

과거 데이터는 재작성하지 않습니다. 배포 전후 평균 체류시간은 측정 기준이 다르므로 단순 비교에 주의해야 합니다. 관리자 상세 분석의 체류시간은 전송된 초의 합계입니다. 기존 일별 집계의 `engaged_sessions`는 한 이벤트가 10초 이상인 세션을 세므로, 여러 짧은 구간을 합친 10초와는 다릅니다. 이 작업에서는 그 서버 지표의 정의를 변경하지 않습니다.

## 검증·배포 범위

합성 시간·이벤트와 가짜 전송기를 사용해 숨김 시간 제외, 30초 차분, 페이지 복원, 중복 종료, 경로 익명화, 세션·페이지뷰 유지 등을 검사합니다. 시험 이벤트는 운영에 보내지 않습니다. 프리뷰와 운영 배포는 분리하고, 지도·캐시·API·DB 변경은 포함하지 않습니다.
